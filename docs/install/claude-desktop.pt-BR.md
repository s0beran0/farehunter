# Instalar o FareHunter no Claude Desktop

[English](claude-desktop.md) · **Português** · [Español](claude-desktop.es.md)

Para **Mac e Windows**. Não precisa de terminal.

## 1. Tenha o Claude Desktop
Baixe em https://claude.ai/download e entre na sua conta. O plano precisa incluir o Claude Code.

## 2. Adicione o plugin
1. Abra as **Configurações** e, em *Personalização*, clique em **Plugins**.
2. Clique em **+ Adicionar** (canto superior direito) → **Adicionar marketplace**.
3. No campo **URL**, digite `s0beran0/farehunter`, escolha **Usar "…"** e clique em **Sincronizar**.
4. Na aba **Descobrir**, clique em **Adicionar** ao lado do **Farehunter**.

## 3. Termine a configuração
1. Abra a aba **Code** e escolha uma pasta qualquer (ex.: `Documentos/viagens`).
2. Digite `/farehunter:setup`.
3. Siga o que ele disser. Ele confere seu computador e mostra o link ou o comando exato da única ferramenta obrigatória (**uv**).

Pronto. Comece com `/farehunter:profile` e depois peça uma viagem, por exemplo `/farehunter:search Porto Alegre para Recife 20/11, volta 27/11`.

## Atualizar
**Configurações → Plugins → + Adicionar → Gerenciar marketplaces**, e sincronize o **farehunter-marketplace**.
